# 梦幻消除战体力提醒器

这是一个可安装为手机桌面应用的静态网页。填写最后一次使用体力的时间和当时剩余体力后，会按每 2 分钟 +1 点、最高 100 点自动计算。

## 手机上使用

1. 将本文件夹部署到任意支持 HTTPS 的静态网站服务。
2. 用手机浏览器打开该网址，点击“开启提醒”并允许通知。
3. 在浏览器菜单中选择“添加到主屏幕”。iPhone Safari 通常为“分享”→“添加到主屏幕”；Android Chrome 通常为菜单→“安装应用”或“添加到主屏幕”。

数据只保存在这台设备的浏览器本地，不会上传。

## 关于满体提醒

当应用保持打开或处于前台时，体力满会立即提示并发送已授权的系统通知。手机操作系统会限制网页在完全关闭后的后台计时；因此若需要在应用关闭后仍保证准时收到通知，需使用原生 App 或后端推送服务。
